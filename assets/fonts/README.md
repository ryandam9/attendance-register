Interface fonts bundled for offline rendering, each under the SIL Open Font
License (see the matching *-OFL.txt file). Users choose one in Appearance.

Source: https://github.com/google/fonts/tree/main/ofl — figtree, dmsans,
manrope, plusjakartasans, nunito and fraunces.

Static weights were instantiated from the upstream variable fonts with
fontTools: weights 400–800 for the text families (DM Sans at optical size 14),
and 400–600 for Fraunces headings (opsz 48, SOFT 50, WONK 0).
